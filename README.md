### 📡 Flagship Project: [TribalNet](https://github.com/ponmudimr/TRIBALNET)
> **RF-Based Off-Grid Disaster Communication & Tracking System**

A solar-powered, long-range **LoRa (433 MHz)** mesh communication network designed to keep remote tribal communities connected during natural disasters when cellular networks, power grids, and internet infrastructure fail.

* ☀️ **Solar-Powered Uptime**: Off-grid operation with Li-ion battery backup.
* 🚨 **Emergency Panic Button & Audio-Visual Warning**: Integrated siren + MAX7219 8x32 LED matrix display.
* 🌐 **Infrastructure-Free**: Zero dependency on GSM, Wi-Fi, or satellite internet.
* 💻 **Central Control Station**: Real-time status monitoring & alert dispatch dashboard for authorities.
